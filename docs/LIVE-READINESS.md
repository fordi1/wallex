# راهنمای بررسی آمادگی اجرا

این نسخه برای سفارش‌ها دفتر ثبت پایدار دارد. قبل از ارسال درخواست، شناسهٔ سفارش ذخیره می‌شود و پس از ری‌استارت، وضعیت همان سفارش از صرافی بررسی می‌شود. قطع پاسخ شبکه به معنی رد شدن سفارش نیست.

## بررسی بدون معامله

از پوشهٔ پروژه:

```powershell
python -m pishro preflight
python -m pishro preflight --online
```

فرمان اول تنظیمات و وضعیت دفتر ثبت محلی را بررسی می‌کند. فرمان دوم فقط اطلاعات بازار، حساب، کارمزد، سفارش‌های باز و مرجع قیمت را می‌خواند. هیچ‌کدام سفارش ارسال یا لغو نمی‌کنند. نتیجهٔ موفق `checks_passed: true` و کد خروج صفر است. مقدار کلیدها و موجودی حساب در گزارش چاپ نمی‌شود.

## تست کد

```powershell
$env:PISHRO_MODE = 'paper'
$env:LIVE_CONFIRM = ''
python -m pytest -q
```

تست‌ها شامل شبیه‌سازی کامل ربات، اجرای جزئی سفارش، قطع پاسخ شبکه، بازیابی بعد از ری‌استارت، خطای ذخیره‌سازی و توقف ریسک هستند. تست‌های اتصال لایو در این دستور وجود ندارند.

## نگهداری وضعیت

- برای هر حساب فقط یک اجرای معاملاتی داشته باشید. قفل برنامه فقط اجرای هم‌زمان با همان پوشهٔ داده را مسدود می‌کند.
- پوشهٔ داده و دیتابیس را روی فضای پایدار نگه دارید. دفتر ثبت سفارش در `kv.execution_state` دیتابیس است. برای تهیهٔ نسخهٔ پشتیبان هنگام اجرا از SQLite backup استفاده کنید؛ کپی تنها فایل `.db` در حالت WAL کافی نیست.
- تنظیم `challenge.end` همچنان فعال است. تاریخ پایان، توقف ورود و زمان خروج برنامه را پیش از استفاده بررسی کنید؛ مقدار منقضی‌شده شروع اجرای زنده را مسدود می‌کند.
- دارایی‌های قبلی حساب خودکار به ربات سپرده نمی‌شوند. پوزیشن‌های نسخهٔ قدیمی بدون دفتر سفارش به تطبیق با سوابق واقعی صرافی نیاز دارند.
- وضعیت `UNKNOWN` یا پیام `reconciliation required` را با پاک‌کردن دیتابیس دور نزنید. ابتدا شناسهٔ سفارش، مقدار اجرا و کارمزد آن را با سوابق والکس تطبیق دهید. دکمهٔ resume خطای حسابداری یا سفارش نامشخص را رفع نمی‌کند.

## نتیجهٔ بررسی این نسخه

بررسی آنلاین فقط‌خواندنی در ۲۳ اکتبر ۲۰۲۶ برای هر پنج بخش موفق بود. هیچ سفارش واقعی ارسال یا لغو نشده و اجرای لایو فعال نشده است. پاس‌شدن تست‌ها و اتصال API، سودآوری یا پرشدن سفارش در بازار واقعی را تضمین نمی‌کند.

جزئیات تغییرات و محدودیت‌های باقی‌مانده در [گزارش فنی](EXECUTION-AUDIT.md) آمده است.
